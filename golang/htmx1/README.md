# Simple HTMLX prototype

## installing templ

Follow the [templ Quick Start](https://templ.guide/quick-start/installation)
Initialize templ for the project (as a tool using the go tool directive added in go v1.24)

```
go get -tool github.com/a-h/templ/cmd/templ@latest
```

To run the temp command to generate the go code from a template
``` 
go tool templ generate
```
